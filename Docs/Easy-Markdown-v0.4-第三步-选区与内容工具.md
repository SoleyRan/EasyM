# v0.4 第三步：选区与内容就地工具

本步在 `feature/v0.4` 上独立实现，基线为第二步提交 `0da2cdc`。产品版本保持 `0.3.0`；本步不发布安装包。仅借鉴交互设计，没有引入 MarkText 代码、资源或许可文本。

## 选区格式

非空且可安全格式化的选区在鼠标释放或键盘选区稳定 160 ms 后显示浮动工具栏，不接管正文焦点。支持加粗、斜体、删除线、行内代码和链接。设置中的“显示选区浮动工具栏”默认开启，独立于固定格式工具栏，并保存到本地；存储失败会提示。

各入口复用统一命令和 false/true/mixed 状态。完全覆盖时取消格式，混合或未覆盖时统一应用，避免重复包裹；反向选区仍保持方向。行内代码选择足够长的反引号围栏，必要时添加并正确移除边界空格。原有围栏代码块按钮保持独立。

继续输入、拖选、滚动、窗口失焦、进入输入法组合、切换模式或任务锁定时隐藏选区工具；调整窗口/侧栏造成编辑区尺寸变化时隐藏旧锚点，下一次稳定选区重新定位。浮层经应用 Portal 显示并按窗口边界限位。Alt+F10 从正文进入工具栏，左右键/Home/End 导航，Esc 关闭后返回正文。

行内格式限同一逻辑行、不超过 10,000 UTF-16 单位；跨行、代码、表格、Front matter、图片、HTML 和不适用的结构标记明确禁用。部分行内代码不能再包成加粗等格式。复杂语法继续提供源码编辑。

## 链接

固定/浮动工具栏、Ctrl/Cmd+K、源码右键及分屏预览点击均进入同一链接工具。普通选区预填 Markdown 源文字、地址留空；现有链接预填显示文字、地址及原有 title。工具支持确认、取消/Esc、解除链接和独立“打开现有地址”。打开动作使用正文中已有地址，不隐式提交尚未确认的输入。

确认只补丁修改当前范围，一次撤销恢复；解除保留显示文字及嵌套行内格式。引用式链接仅转换当前使用处，保留共享定义和其他引用；界面说明这一行为。嵌套链接、图片、HTML 和非法括号不写入正文。

允许 http/https/mailto、标题锚点与相对文档路径，拒绝其他协议、协议相对地址、凭据、控制字符和绝对文件路径。桌面外部地址通过受限 `open_external_link` 命令调用系统关联程序；不执行 shell。浏览器演示用独立窗口并隔离 opener。

相对 Markdown 文档仅通过已授权工作区打开，按当前文档目录解析，拒绝越过根目录，沿用后端授权/符号链接/文件校验。可附标题锚点；已打开目标复用标签，保留内存编辑。重复打开受并发保护，取消后过期结果不切换标签；回收未使用句柄时检查是否已被其他标签持有。浏览器演示及工作区外单独打开的文档不会获得额外路径访问权。

标题锚点按标题文字的小写形式、标点移除、空白转连字符和重复项后缀匹配；未找到目标保留正文并提示。查找结果仍使用原有 revision 校验，链接锚点则在目标标签当前内存正文中定位。

## 代码语言与段落转换

即时渲染和分屏预览的围栏代码块显示实际语言，可搜索中文名称/英文标记，选择常见语言或无语言。未知标记保留为自定义项，不自动映射到相近语言。源码模式保留原语言下拉框，并可通过右键打开搜索工具。

修改仅针对 info string，保留代码正文、围栏字符和长度、前后文字；选择相同语言不产生正文修改或撤销。无语言沿用既有约定，移除整个 info string，防止 metadata 被当作语言。预览高亮随语言更新，未知标记保持纯文本。

固定工具栏和源码右键提供“转换为”，说明完整作用行范围，支持正文、H1–H6、无序/有序/任务列表和引用。保留行内 Markdown、中文/emoji、目标外内容以及 BOM/CRLF；setext 标题连同下划线正确处理。不重写全文，不转换代码/表格/Front matter/HTML 或复杂嵌套结构。

就地解析暂限 1 Mi UTF-16 单位并缓存当前正文 AST，转换范围限 100,000 单位。超过限制禁用工具并保留源码。命令面板入口在第四步接入，不提前实现第四步。

## 生命周期与验证

内容输入工具使用共享模态浮层和焦点循环；打开时捕获文档、revision、选区和代码/链接/段落目标，期间锁定正文并暂停该文档自动保存。输入法组合期间不接受确认/取消或快捷键操作。确认重新校验目标，失败保留输入和原文；取消不修改正文，返回有效源码选区。

新增 `pnpm verify:content-tools` 并纳入 `pnpm verify:regression`；CI 上传报告及主题/紧凑窗口截图。检查包含真实鼠标拖选、键盘进入/关闭工具栏、格式状态、撤销、链接编辑/取消/引用、安全地址、语言真实高亮/无语言/未知标签、段落转换、合成输入法事件、四主题、紧凑窗口和设置重载。独立桌面 IPC fixture 检查相对打开/锚点、越界拒绝、外部打开参数及取消后不释放已有文件句柄。

证据归档于 `Docs/verification/v0.4/step-3/`，具体结果见 `acceptance.json`，临时日志留在 `test-results/`。前端全量单测、生产构建/类型检查、版本一致性、Windows Rust 测试和完整生产浏览器回归均作为本步门槛。

IPC fixture 不等同真实文件/系统关联程序交互，合成 composition 事件不等同中文 IME 候选验收。原生链接打开、真实 IME、macOS/Linux GUI 和当前源码的远端 CI 留待相应环境验证；不以本机 Chromium/Rust 测试替代这些记录。既有大包体构建提示和 React 测试 act 提示已记录，未作为本步排版或性能扩展。
