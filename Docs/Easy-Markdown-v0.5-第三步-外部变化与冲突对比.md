# EasyM v0.5 第三步：外部变化与冲突对比

日期：2026-10-14。分支 `feature/v0.5`，基线 `ab529af`。产品版本仍为 `0.4.0`。

## 用户行为

打开本地文件、切回应用/文件标签、关闭阻塞操作后，后台检查已授权文件的磁盘原始字节版本。检查只读取正文，不写入正文、图片元数据、草稿或历史。未修改文档保持当前正文并提示加载；存在本地修改、图片配方或表格输入时保留这些内容，暂停自动保存。

提示提供比较外部版本、重新加载磁盘版本、另存本地副本和重新检查。缺失、类型变化、权限撤销、超过 10 MiB、非法 UTF-8 或超时均保留内存正文，显示对应错误。浏览器没有原生文件句柄，不显示虚假的外部变化检查。

比较窗口展示「磁盘 → 本地」逐行差异和双方全文，可用鼠标/键盘选择复制，定位本地差异、另存副本、保留本地编辑或确认加载。BOM/换行变化即使规范化正文相同也会提示；显示磁盘编码和换行格式。差异计算失败或超过限制时仍展示双方全文。窗口支持四种主题、小窗口内部滚动和按钮换行。

加载前保护未保存正文；比较窗口二次确认，原生端核对刚才比较的磁盘 revision，文件再次变化时拒绝加载。图片会话未确认/取消和表格输入未应用/放弃时，不允许用重新加载绕过未提交输入保护。表格可以继续应用到本地正文，自动保存仍暂停；图片提交会拒绝写入变化的磁盘，保留配方与正文。另存沿用现有资源完整性规则，不猜测图片合并。

## 实现契约

原生 `inspect_document(id, expectedRevision)` 仅接受当前进程授权句柄，从登记路径逐级拒绝符号链接、Windows reparse point 替换，检查类型和大小，有界读取最多 10 MiB + 1 字节。SHA-256 基于原始字节，不依据修改时间或规范化文本。版本未变时仅返回 revision，变化时返回正文供比较；不调用事务 recover 或历史写入。磁盘读取位于阻塞任务中，释放注册表锁后读取。

`reload_document` 增加可选 `expectedRevision`。用于确认加载时，先读取/校验字节 revision，再执行既有恢复与资源元数据流程。应用成功保存、图片应用、历史恢复和批次提交仍更新编辑器基准 revision；现有 optimistic save 冲突契约保留。

`useExternalChanges` 按文件 ID、基准 revision、活动/阻塞状态划分检查代次；原生窗口 focus、WebView focus 和 visibility 事件按 150 ms 去抖，不因每次正文输入读取磁盘。同一编辑器只保留一个原生读取，旧代次或超时结果丢弃；切换后的任务等待旧读取释放槽位，等待超时也显示可恢复错误。10 秒前端超时不能强行终止操作系统正在执行的读取，因此不再不断创建并发任务。离开/卸载清理监听和定时器，保留当前正文。

检测结果与普通操作锁分离，通知不阻止编辑本地正文或草稿保存；检查期间、变化/读取失败未处理时阻止自动保存和原位置手动写入。另存副本、历史/图片原有 revision 校验和重新加载的明确处理流程保留。模态比较窗口使用现有浮层与焦点管理，Tab 可进入双方只读正文，Escape 只关闭窗口。

差异复用本项目现有 Worker：最多 5 MiB/100,000 行、2,000,000 trace cells、10 秒；最多展示前 4,000 行差异，双方全文仍可查看。未增加第三方运行时依赖，不复制 MarkText 源码或资源。

## 验证与限制

新增 Hook 单测覆盖同正文不同 BOM/换行、旧标签结果丢弃、单任务去重、focus 去抖、10 秒超时/旧任务等待、缺失和非法编码保护。Rust 测试覆盖原始字节哈希、无副作用读取、缺失/类型/超限目标保留、对比 revision 变化拒绝加载；Unix 父目录符号链接测试需 macOS/Linux CI 执行。

`pnpm verify:external` 使用真实生产 Chromium 和 CodeMirror、受控原生 IPC，覆盖干净/脏正文、复制选区、Escape、显式加载、比较后再次变化、另存保留原文件、缺失/权限/超限重试、自身保存更新基准、旧标签迟到结果、BOM-only、表格未提交输入、图片未提交配方、小窗口和主题截图。已加入全量生产回归与 CI 证据收集。

本机 45 文件 / 250 项前端测试、64 项 Windows Rust 测试、23 组生产回归及类型检查、构建和版本元数据核验均通过，结果见 [验收汇总](verification/v0.5/step-3/summary.json)。单测与生产回归由本机 PowerShell 调用；Chromium 无界面运行，完整输出在 `test-results/v0.5-step3-*.log`，验收报告及关键截图另存入本目录的 `verification/v0.5/step-3/`。

尚未完成真实三平台 GUI、原生焦点/权限撤销、系统对话框、真实 IME、Unix 符号链接的本机验收；不将浏览器 IPC fixture 等同实机。切回/手动检查后发生的外部写入仍靠保存 revision 拒绝覆盖，未引入常驻目录监视或三方合并。第四步负责完整交付性能、说明、版本升级和安装包；本步未打包、未推送。
