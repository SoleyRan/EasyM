# EasyM v0.4 第一步：统一命令与浮层

日期：2026-10-13。分支：`feature/v0.4`。范围冻结提交：`7029495`。产品版本保持 `0.3.0`，本步不发布安装包。

## 实现

`src/core/commands.ts` 提供命令目录和注册表，包含稳定 ID、中文名称、英文别名、分组、快捷键、可用原因、格式选中/混合状态及执行函数。应用负责设置和模板命令，每个文档实例负责自己的正文、文件、视图和导出命令，运行时读取当前上下文，避免执行其他标签或旧正文的操作。

EM 菜单、固定格式工具栏、编辑区右键及快捷键共用注册表。格式开关、代码语言修改先生成 `EditCommandResult`，再由 CodeMirror 一次应用局部补丁；沿用同一个撤销栈。执行前检查文档/文件身份、正文 revision、选区方向、阅读模式、组合输入和任务锁。修改前验证所有范围及结果选区，拒绝重叠、越界和过期结果；无正文变化不派发修改事务。

捕获选区时显式读取 `anchor/head`：CodeMirror 的选区坐标通过原型访问器暴露，不能依赖对象展开复制。异步右键剪贴板操作还检查原编辑器、正文对象、选区和当前锁状态，避免读取完成后覆盖新编辑。

保留 `Ctrl/Cmd+P` 打印、`Ctrl/Cmd+Shift+P` 插图及现有格式快捷键；格式快捷键从命令目录生成。后台自动保存继续允许正常正文输入，通过原有保存 revision 机制保留保存期间的新修改。模态或阻塞任务期间编辑器使用 readOnly compartment，不重建编辑器或撤销记录。

`src/core/overlays.ts` 和 `src/editor/Overlay.tsx` 提供浮层优先级、父子关系、代次身份、应用宿主及定位。EM、导出子菜单和右键通过 Portal 放到主题容器内的宿主，脱离编辑区和顶栏的裁剪/层叠上下文；尺寸变化、滚动、窗口缩放和指针移动重新定位，空间不足时翻转或限位。首次定位在绘制前完成，使键盘焦点能进入可见菜单；后续 RAF 带身份检查并在卸载时取消。

菜单与右键互斥，模态拒绝无关的低层菜单；导出子菜单和模态输入框右键有明确父层。关闭父层会失效其子层，旧关闭/定位回调不能影响新的浮层。Esc 只消费最上层菜单，之后才允许关闭查找或退出阅读。焦点恢复检查目标存活、隐藏/inert 状态和管理器代次，避免抢走新菜单或新弹窗的焦点。

设置、导引、模板、关闭确认、图片、历史、批图和导出弹窗接入同一生命周期。现有固定定位的模态 DOM、焦点循环、忙碌/取消及原生 IO 规则保留；本步迁移 Portal 的对象为主动菜单和右键，后续就地工具使用同一宿主。图片未完成时再打开关闭确认采用父子模态关系，取消确认后底层弹窗仍受保护。

## 自动化验证

验证报告归档在 `Docs/verification/v0.4/step-1/`，运行中的日志与临时输出写入忽略目录 `test-results/`。新增 `pnpm verify:commands` 并纳入 `pnpm verify:regression`，CI 同时上传其报告。

- 命令契约单测覆盖目标/文件/revision/反向选区过期、CodeMirror 实际选区捕获、组合输入/任务锁/阅读状态、UTF-16 范围、原子补丁和无改动操作。
- 浮层单测覆盖替换与优先级、子菜单、父层释放、嵌套模态和过时代次、窄窗口翻转/限位。
- 新增生产浏览器检查覆盖格式快捷键/工具栏和一次撤销、查找上方菜单点击、方向键和逐层 Esc、菜单替换与模态防护、窄窗口、组合输入、打印/插图快捷键及阅读 Esc。
- 保留全部旧回归断言，包含四主题真实鼠标正反向拖选和工具点击保持选区、右键剪贴板竞态、文件/草稿、同步滚动、图片/批图、历史、DOCX、HTML 和打印流程。

最终结果：typecheck、build、版本清单和差异检查通过；34 个测试文件、191 项前端测试通过；Playwright Chromium 的 16 组统一生产回归通过，Edge 的命令与右键专项通过。结果见 [acceptance.json](verification/v0.4/step-1/acceptance.json)、[统一回归报告](verification/v0.4/step-1/regression-verification.json) 和同目录原始日志；[菜单截图](verification/v0.4/step-1/em-menu-tabs.png) 已检查主题继承和右侧子菜单布局。报告记录未提交实现的文件 SHA-256 和构建首页 SHA-256，本步代码留在工作区等待下一次提交。

首次完整回归使用 Edge 时，DOCX 下载检查把 `edge://downloads-hub` 与 `edge://resources` 内部资源计入了外部请求，导致误报；随后完整回归使用 Playwright Chromium，不放宽应用对远端请求的断言。Edge 专项命令与右键检查另外保留。浏览器回归也发现并修复了右键宿主层级和菜单首次定位导致的焦点问题。

## 后续边界

本步没有实现可视化表格、选区工具、链接弹层、段落转换、`/`、F1 命令面板或快速打开；这些依照冻结顺序分别在第 2–4 步完成。

浏览器组合事件验证不能替代真实输入法候选交互。macOS/Linux 原生窗口、原生文件/打印对话框、读屏与本轮远端 CI 尚需后续实机或 CI 验证。Rust 代码及依赖未修改，本步不重新执行 Rust 全量测试或生成 Windows 包。构建保留已有主包超过 500 kB 的提示，作为第 5 步排版与回归交付时的性能评估输入。

实现独立编写，没有导入 MarkText 代码、资源或许可文本。
