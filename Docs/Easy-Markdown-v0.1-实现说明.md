## 本轮可靠性实现

### 关闭保护

`src/platform/window.ts` 拦截 Tauri 原生关闭事件。正文有未保存修改或图片面板有待应用操作时，由 `CloseDialog` 提供四个动作：

- 返回编辑：保留当前文本和图片面板；
- 保留草稿并退出：等待 IndexedDB 写入完成后关闭；尚未到自动保存防抖时间的修改也会保存；
- 不保存退出：清除所关闭文档的正文/图片恢复草稿，丢弃未保存修改；不会写入磁盘文件；
- 保存并退出：文件确实写入磁盘且仍是当前文本版本才关闭；保存对话框取消或写入失败时保留窗口。

图片尚未应用时禁用“保存并退出”，可返回应用图片、保留图片草稿退出，或明确丢弃。文件保存、图片生成/应用期间拒绝关闭并提示等待。草稿写入/清理失败同样取消退出。已有未处理的恢复草稿不会因未修改文档直接退出而被清除。

### 图片草稿

`Draft.imageSession` 保存源 Blob、原始尺寸、recipe、Alt、源选区、目标引用、正文基线、实例、operationId 和显示副本标识。恢复时只有正文基线匹配才恢复面板；恢复文档作为应用副本另存，避免覆盖旧文件。图片面板操作更新后参与草稿防抖保存；草稿同时尝试补齐已托管图片资源，资源不完整时保留正文草稿并明确报错。

### 保存事务与恢复

`src-tauri/src/transaction.rs` 将保存分成图片资源、准备日志、正文、元数据阶段。每次操作使用 UUID，在 `.easym/operations/op-<operationId>.json` 中记录文档、旧/新正文哈希、待提交元数据和完成状态。

正文替换前再次核对磁盘哈希；资源写入期间出现外部修改也会拒绝覆盖。正文提交前失败保留旧正文，已生成的不可变资源可以保留供重试。正文提交后元数据失败返回警告，不把已保存正文误报为回滚；再次打开只在当前正文哈希匹配日志时补交元数据。相同 operationId 的相同内容可重试，复用 ID 提交不同内容会被拒绝。

源副本不可变，损坏图片不会留下可见资源；Windows 嵌套相对路径兼容反斜杠。损坏或较高版本元数据不会被静默覆盖；正文仍可读取。日志和历史资源尚未提供自动清理功能。

### 后台预览

`src/editor/usePreview.ts` 通过独立 Markdown Worker 解析正文，120 ms 合并输入并使用递增修订号丢弃过期结果。图片编辑和预览定位还会核对解析所用正文；解析失败时提示错误并保留源码编辑。像素处理继续使用独立图片 Worker。

## 冻结后实现补充记录（2026-10-09）

本轮保持 Markdown 唯一正文来源、schemaVersion=1 和 ImageRecipe v1，记录以下平台/实现决策：

- Worker 使用内联 Blob，由 CSP `worker-src 'self' blob:` 授权执行。依赖解析优先选用 Worker 条件，避免字符实体解码库在生产 Worker 中访问 `document`。`verify:workers` 检查真实产物无 DOM 初始化，`verify:browser` 在真实浏览器中验证解码和完整闭环；不扩大正文 HTML 的执行权限。
- 目录访问先由系统选择器授予工作区 ID；后续命令只接收 ID 和相对路径。树按目录展开加载，跳过隐藏目录、node_modules、target、符号链接与越界条目；不向前端开放任意绝对路径读取。
- Tauri 的 `dragDropEnabled` 设为 false，交由 CodeMirror 的 HTML5 拖放处理，以保留树内图片载荷和落点选区。该平台行为仍需要三平台真实 WebView 验收。
- Windows CF_HDROP 读取只由显式粘贴触发。读取文件列表后先释放剪贴板，再按 PNG/JPEG 格式、20 MiB 字节和像素限制读取/解码；多张图片给出提示。系统截图优先使用 DOM 图片数据，普通文本粘贴保留原行为。
- 浏览器文件选择器在选择/取消期间保持连接到 DOM，结束后移除，以兼容真实浏览器和自动化文件选择。
- 普通窗口失焦/隐藏时再次尝试保存草稿；忙碌的图片/保存操作期间不把不完整操作写为完成状态。

### 多文档与配色范围补充

2026-10-09 用户试用后明确要求扩展以下行为，作为当前开发候选的一部分：

- `App` 管理标签与窗口退出；`DocumentEditor` 管理单文件正文、编码、基线哈希、图片资源和保存状态。后台标签保留挂载，切换不重置 CodeMirror 撤销、选区和滚动。打开文件、新建文档增加标签；原生重复打开同一规范路径切换到原标签，不丢弃已有修改。另存目标已被其他标签打开时拒绝覆盖，关闭标签释放文件授权会话。
- 草稿数据库版本保持 1，旧 `current` 草稿继续兼容；新文档以 `document:<uuid>` 独立保存。重启发现全部保留草稿，逐标签明确恢复为应用副本。清理/保存一个标签不影响其他草稿；不兼容草稿保持原数据并禁用该标签编辑，仍可编辑其他标签或保留草稿退出。
- 关闭一个未保存标签提供返回编辑、不保存关闭、保留草稿并关闭、保存并关闭。关闭窗口先检查全部标签，再逐个保存、刷新或丢弃草稿；取消、失败均不会误关闭。图片面板和中文组合输入期间阻止标签切换，避免操作落到其他文档。
- `themes.css` 用 CSS 变量提供清爽浅色、午夜深色、暖纸、护眼绿，覆盖编辑器、预览、工具栏、代码 token 和图片面板。主题写入本地 `easym-theme`，不修改 Markdown 文件或图片元数据；无需网络、远程字体或脚本主题。
- 自动化范围增加独立标签编辑/撤销/草稿恢复、单标签保存隔离、窗口批量保存取消、不兼容草稿保护和主题记忆。全部标签保留挂载会随打开文档数增加内存，目前未实现后台标签卸载。

### EM 菜单、侧栏与定位补充

- 应用产品名与窗口标题统一为 EasyM，SVG 几何字形为 EM；使用 `pnpm.cmd icons` 生成 Windows/macOS/Linux 与移动端图标，应用标识与现有草稿数据库保持兼容。
- `App` 顶部只渲染一份 EM 菜单，调用活动文档的操作句柄；支持点击外部/Escape 关闭、方向键选择。紧邻 EM 的单行标签栏水平溢出时，把滚轮上下动作映射为标签左右浏览，切换标签自动显示活动标签；标签完整名称可悬停查看。
- `ResizableSidebar` 使用 Pointer Capture 拖拽，左栏向右、右栏向左拖动增加宽度，范围 160–420px；拖拽受中央区域剩余宽度约束。分隔条可用左右方向键/Home/End 操作，两侧宽度分别保存在 `easym-sidebar-left/right`。当前文件和树节点均采用省略号，完整文件名保留在 title。
- 大纲与预览块点击都显式重置滚动发起方并定位两侧，即使源码标题已可见也驱动预览。CodeMirror 定位靠近视口顶部，随后继续使用双向同步。
- 不保存关闭先阻止自动草稿写入，作废并等待已排队写入，再清理目标草稿；窗口关闭失败时恢复草稿保护。仅清理被关闭标签，不写入正文文件，也不删除已落盘图片资源。
- 新增集成回归覆盖丢弃单标签/全部标签、窗口关闭失败后恢复保护及菜单 Escape；浏览器回归覆盖重复大纲点击、预览滚动后的定位、两侧真实指针拖拽、宽度记忆、长名称省略和标签滚轮。

- 工作区与文件栏可见状态由窗口共享；点击树中文档或切换标签不收起文件树。
- 视图栏的“格式工具栏”按钮切换格式按钮显示，偏好记入 `easym-toolbar`；隐藏后快捷键仍可用，正文占用释放的高度。
- 表格单元格使用主题适配的 1px 边框、内边距、表头与隔行底色，保留 GFM 列对齐，宽表在表格内部横向滚动。
- 新增 React 集成测试覆盖自动保存防抖、未命名/恢复文档不弹选择器、写入中编辑、草稿清理中编辑、冲突暂停/手动重试、关闭丢弃、混合换行与 IME 等待。Edge 回归验证工具栏显示偏好、正文高度增加、打开文件保留侧栏、四种主题表格边框和列对齐。

- Tauri decorations=false 移除系统标题栏；EM 顶栏最右侧提供最小化、最大化/还原与关闭按钮，颜色使用当前主题变量。顶栏空白可拖动、双击最大化/还原。自定义关闭复用未保存文档保护流程，不直接销毁窗口。
- Style 选择移入 EM 菜单，点击 Style 后在右侧展开四个单选菜单项，方向键可访问，持久化沿用 easym-theme。
- 底部字数按 Markdown 源文的非空白 Unicode 字符数统计（包含语法标记，emoji 单个码点计一次），与行数共同显示，停止输入约 250 ms 后更新，避免整篇扫描阻塞按键帧。
- 阅读模式取代专注模式。通过窗口 API 进入全屏，隐藏 EM 顶栏、源码及格式工具栏；视图栏仅保留文件树、大纲、退出阅读模式。预览和底部状态栏保持显示，支持只在预览中大纲定位，双击图片不进入编辑操作。
- 编辑器保持挂载而隐藏，退出时恢复原视图、正文、撤销栈与选区。阅读中可从文件树切换文档。退出按钮或 Esc 恢复进入前的全屏状态；监听窗口/浏览器全屏变化，系统退出全屏时也退出阅读布局。全屏请求失败时保留可编辑界面并提示。
- 窗口动作封装在 platform/window.ts；权限只增加必要的最小化、最大化、状态查询、全屏与拖动。集成测试验证关闭保护、主题菜单、阅读恢复、Esc/按钮退出、全屏失败和外部状态更新；真实浏览器回归验证全屏、只读预览、大纲、三按钮布局与退出后正文保留。原生最小化/拖动/最大化和跨平台全屏仍需手工验收。

### 标签栏与菜单细节补充

- 标签栏滚动条保留 3px 固定空间但默认透明，鼠标移入顶栏后显示低对比主题色，不因显隐改变布局；上下滚轮浏览标签保持可用。无 WebKit 滚动条的浏览器使用 thin 回退。
- 新建文档初始为未修改，只有实际正文编辑或待应用图片才触发关闭保护；未编辑时不创建空白恢复草稿，关闭标签/窗口直接完成。
- Style 主题仅在点击后显示右侧子菜单，支持方向键、Escape/左箭头返回父菜单、右箭头进入、选择后关闭，沿用主题记忆。
- 新增测试覆盖未编辑标签直接关闭、未编辑多标签直接退出、编辑后关闭保护与子菜单层级键盘行为；浏览器检查滚动条悬停样式/厚度/布局、主题菜单右侧位置和空文档直接关闭。

### 依赖交付清单

`Docs/dependencies/THIRD-PARTY-NOTICES.md` 与 `sbom.cdx.json` 记录 Windows 的 406 个依赖版本（pnpm 生产依赖、目标过滤后的 Cargo resolve graph 中构建与运行依赖）。Windows 完整许可文本缺项为 0；补充上游文本的 commit/来源和 SHA-256 位于 `license-sources.json`，提取说明见 `scripts/external-licenses/README.md`。Linux 清单 502 项，补齐 dlopen2、dlopen2_derive 和 libappindicator-sys 后缺项为 0；macOS arm64 清单 401 项，12 个 objc2 家族包仍缺完整文本。分平台摘要见 `Docs/verification/dependency-inventory-*.json`。

`generate-notices.mjs` 接受输出目录与目标参数，生成 notices、SBOM、来源和 inventory；默认报告缺项，`EASYM_STRICT_LICENSES=true` 时因缺项失败。CI 在桌面构建前按本机 Rust host 重新生成 `Docs/dependencies/`，确保安装器资源与当前目标一致，并上传完整目录。声明扫描不是发行法律复核，macOS objc2 的上游 LICENSE.md 只有声明和 Apple SDK 来源说明；MPL 源码可用性及 SDK 派生条款仍需复核。

Windows 便携开发包 `src-tauri/target/release/bundle/portable/EasyM-0.1.0-windows-x64-dev.zip` 已包含程序、项目 LICENSE 和上述第三方文件；解压后运行，要求系统已有 WebView2 Runtime。`scripts/package-portable.ps1` 生成 ZIP 并验证路径、重复条目、必需文件和内嵌程序哈希，具体校验值见 `Docs/verification/windows-build.json`。NSIS 首次工具下载曾超时，重试下载并通过官方哈希校验后，已利用项目内缓存重新生成 `src-tauri/target/release/bundle/nsis/EasyM_0.1.0_x64-setup.exe`；安装包同样附带 LICENSE 与 `third-party/` 资源。`verify-installer.ps1` 只在没有已有安装的 disposable Windows CI runner 验证安装/启动/卸载；新增 CI 步骤尚未执行，安装包未签名。

### 超长行性能降级

物理行超过 20,000 字符时，CodeMirror Compartment 暂停整篇源码 Markdown 语法支持；正文、撤销、选区和后台预览完整保留，状态栏说明降级。行缩短后自动恢复语法支持。`largeLines` StateField 初次统计全部行，随后仅统计变更触及的旧/新行，避免每次输入重新扫描全文；测试覆盖连接、拆分、多处编辑和阈值。生产性能脚本另确认恢复高亮、撤销后重新降级和完整预览。
