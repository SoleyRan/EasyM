# EasyM v0.1 已知限制

更新日期：2026-10-09。当前为未签名开发候选；完整证据见 [验收记录](Easy-Markdown-v0.1-验收记录.md)。

## 数据与恢复

当前自动化未发现静默覆盖外部正文、改写源图片或越界写入等冻结文档第 9.4 节的阻断缺陷，但真实平台覆盖仍有缺口，不能据此宣称全部场景无风险。

| 限制 | 当前行为与恢复方式 |
| --- | --- |
| 外部版本与本地编辑冲突 | 自动写回暂停，保留草稿；通过 EM 菜单另存冲突副本或重新加载外部版本。没有三方合并。 |
| 混合换行 | 自动写回暂停，手动保存时明确确认换行策略。 |
| 损坏/高版本图片元数据 | 保留正文可读性并提示恢复受限，不静默覆盖元数据；另存副本处理。 |
| 未托管或缺失的本地图片 | 另存为会拒绝生成引用不完整的副本；先导入图片副本再保存。 |
| 正文提交后元数据失败 | 已保存正文不回滚，返回警告；再次打开时，仅在正文哈希匹配操作日志时补交元数据。 |
| 恢复草稿 | 恢复为应用副本，明确另存；不直接覆盖原磁盘文件。 |

## 功能与体验

| 限制 | 当前范围 |
| --- | --- |
| 即时渲染/完整富文本编辑 | 保持禁用，稳定路径是源码、分屏和只读阅读模式。 |
| 超长物理行 | 超过 20,000 字符时暂停整篇源码 Markdown 语法支持；缩短后自动恢复。正文、预览和撤销保持完整。 |
| 超大围栏代码块 | 预览单块超过 100,000 字符时跳过 token 高亮，完整显示纯文本。 |
| 长代码块/表格内部滚动同步 | 按块插值近似，无法保证逐像素对应。 |
| 多文档内存 | 后台标签保持挂载以保留撤销/选区，打开越多内存越高；没有后台标签卸载。 |
| 资源与日志清理 | 历史图片和 `.easym/operations/` 不自动删除，避免误删被草稿/历史引用的资源。 |
| 浏览器保存 | 下载 Markdown 或完整工作区 ZIP，不覆盖原本地文件。 |
| 远程图片与执行型 Markdown | 默认不请求网络图片；不执行脚本、MDX 或 Mermaid。 |
