# EasyM v0.6 设计与实施计划

冻结日期：2026-10-14。分支 `feature/v0.6`，从已合并 v0.5 的 `main` 提交 `90c4ce7` 创建。按四个完整步骤推进，每步实现、验证和记录后再进入下一步；本轮按用户指令提交第2步后实施第3步，不自动推送或进入第4步。

## 目标与边界

完善 Markdown 扩展的输入—预览—导出闭环。Markdown 原文是唯一正文，显示与导出不改写正文、编码/BOM/换行、草稿、图片事务或撤销。沿用 CodeMirror、共享 AST 与后台 Worker；不增加插件运行时、MDX/任意 HTML 执行、PlantUML/Graphviz、直接 PDF 引擎、云同步或自动三方合并。MarkText 只借鉴设计，不复制其源码、资源或文案。

前三步保持产品版本 `0.5.0`，最后交付统一为 `0.6.0`。以前的验收记录保留；每步新证据放入 `Docs/verification/v0.6/step-N/`。新依赖须记录许可/SBOM与构建体积变化，Windows 清单不能代替全部平台的许可验收。

## 第1步：脚注与 Front Matter

脚注采用既有 GFM 解析，语法为 `正文[^标识]` 与 `[^标识]: 说明`，缩进四空格可继续段落。按首次引用顺序编号，多次引用同一标识共享正文并可返回各引用；标识大小写按解析器规则归一化，首次定义生效。缺失定义保持普通文本；未引用/重复定义不静默消失，预览和导出按静态原文保留。

分屏和阅读模式显示脚注区，引用/返回可用鼠标或键盘导航；目标严格限制在当前文档预览 DOM 内，不能跨标签或打开外部页面。分屏可同步定位对应源码，阅读模式仅滚动及焦点定位，不编辑。过期 Worker 结果不导航。即时渲染首步保留脚注引用及定义的源码编辑，不承诺行内可视化脚注工具。

HTML 导出包含静态脚注和有效内部锚点；系统打印/PDF 打印文末脚注区，不承诺真正的逐页页脚。DOCX 首步以可编辑的上标编号和文末“脚注”段落表达，不冒充 Word 原生页脚脚注；预检说明降级，脚注内的格式、列表、链接/图片沿用现有映射及资源安全/限额。未引用/重复定义的原文附录保留。循环引用仅生成每份定义一次，不递归展开内容。

Front Matter 仅识别文件开头合法围栏 YAML `---` 或 TOML `+++`。预览/阅读与 HTML/PDF 展示带类型说明的静态完整原文（含围栏），不解析/执行元数据，不让标题、路径、主题或插件配置获得权限。DOCX 保持静态原文并说明。源码和即时渲染保留编辑语法；未闭合围栏不推测转换；中途分隔线仍按普通 Markdown。无元数据表单和 YAML/TOML 自动重写。

验收覆盖重复引用、定义顺序、中文/特殊标识、缺失/未引用/重复定义、循环引用、多段/嵌套内容、图片权限/预检、四主题/紧凑窗口、键盘导航、不同标签隔离、导出静态内容/锚点、撤销/下载不改原文、YAML/TOML及恶意/未闭合样例。修复既有安全清理引起的锚点不匹配，不关闭 HTML 清理或 DOM clobbering 防护。

## 第2步：数学公式

接入受限数学渲染：行内 `$…$` 与块级 `$$…$$`，文本含普通货币符号和代码时不误转换；使用可审计的 KaTeX 类方案，禁用信任/外部资源及危险命令，限制公式长度、展开次数和输出。源码继续可编辑；预览/阅读错误显示原文及说明，不阻塞其他内容。即时渲染按当前活动块回源码，异步结果绑定身份/版本，取消和超时保留文字。

冻结具体依赖版本、公式语法及 HTML/系统打印/DOCX 的源文或图片降级契约后再实现；导出必须显式说明，不等第4步才发现无法表示。设置提供公式渲染开关，关闭后保留源码显示。

## 第3步：Mermaid

首批保证流程图与时序图，围栏语言 `mermaid`；其他图类型明确提示超出本轮保证。懒加载受限渲染、主题适配、语法错误/大图/超时回退源码；禁止脚本、交互 click 指令、外部读取和文档内修改安全配置。SVG 清理脚本/事件、外部引用和危险 URL，源码始终保留。设置提供 Mermaid 渲染开关，启用不执行普通代码块。

具体引擎版本、可安全离线渲染的运行环境及 SVG/图像导出方案在本步冻结验证后接入；HTML/PDF/DOCX 均需明确一致的图像或源码降级，不使用未经清理的 SVG 或联网服务。

## 第4步：统一导出、回归与交付

汇总扩展能力/降级说明，补齐导引和 v0.6 样例；核对 HTML、系统打印/PDF与可编辑 DOCX 表现、离线资源和源文保存。统一版本及依赖许可清单，运行前端单测、生产全量回归、性能、涉及原生层的 Rust/三平台 CI、Windows 启动/安装/便携包检查，生成 Windows 0.6.0 开发包。

不把浏览器 fixture 当作真实 IME、系统打印分页、屏幕阅读器或 macOS/Linux GUI 验收；继承 v0.5 的人工/签名/发行与 macOS 许可文本待办。正式发行、平台验收与扩展功能完成分别记录。
