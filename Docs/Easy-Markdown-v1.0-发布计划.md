# EasyM v1.0 发布计划

开始日期：2026-10-16。分支 `feature/v1.0`，基于 `main` 的 `3c40370`。该基线的三平台 CI [38875137835](https://github.com/SoleyRan/EasyM/actions/runs/38875137835) 已通过。

## 冻结范围

v1.0 收敛现有桌面功能，不再增加功能阶段。包括三种编辑视图、多文件与工作区、搜索和模板、图片处理、主题与阅读、Markdown 扩展、HTML/DOCX/系统打印、自动保存与草稿、历史、外部冲突合并及单文档备份。保持文档、图片、历史、备份和本机设置格式兼容；不改应用 identifier、草稿键或历史 schema。

Web/PWA、移动端、同步、协作、AI、插件、完整工作区备份、DOCX 导入、专用 PDF 引擎不作为 1.0 前置条件。仅借鉴 MarkText 设计，没有复制其代码或资源；本项目继续使用 Apache-2.0，实际第三方依赖保留各自许可。

## 收尾顺序

1. 统一 1.0.0 版本、稳定版标识、发行样例、升级说明、已知限制和恢复文档；补齐 macOS 依赖许可，三平台均启用严格许可检查。
2. 建立可复核的三平台发布包与 SHA-256 清单、GitHub Release 草稿流程（复用同一提交成功 CI 中的候选，不重新构建）。首发构建目标为 Windows x64 NSIS/ZIP、macOS Apple Silicon DMG、Linux x86_64 DEB（Ubuntu 24.04 构建环境）；Intel Mac、Windows ARM 和其他 Linux 发行版不冒充已验证。候选必须绑定具体提交、版本、测试结果及包哈希；失败不得发布。签名、更新方式在本轮明确决定，不把未签名包称为已签名，也不声称已有自动更新。
3. 运行完整自动验收：前端单测/构建、Rust、生产功能回归、慢速交互、性能、Word、Windows 原生启动/离线扩展、NSIS/便携包。CI 验证三平台并在一次性 Windows runner 安装/卸载。所有证据写入新的 `Docs/verification/v1.0/`，不覆盖旧版验收。
4. 根据用户已确认的安排，三平台同时正式发布，等待补齐实机验收。Windows、macOS、Linux 均需验证真实输入法、原生对话框、保存/重启和恢复操作；正式发布前完成使用者验收及签名决策，创建对应提交的 `v1.0.0` 标签和 Release。当前尚未发布。

## 发布阻断与边界

保存/恢复静默丢失、覆盖外部新版本、损坏历史/图片、路径逃逸，以及候选提交的必需 CI 失败均阻止发布。已明确说明的能力边界无需为 1.0 新增功能。真实 IME、原生选择器、读屏和跨平台 GUI 的未验项目必须如实记录，不以浏览器模拟替代。

原路线中的三平台正式支持、签名更新不能仅通过改版本号宣称完成。用户已选择三平台同时正式发布、等待实机验收，不采用 Windows 提前正式发布。当前候选未签名、无自动更新；正式分发方式待签名问题答复后确定。
