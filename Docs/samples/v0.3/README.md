# v0.3 冻结验收样例

复制整个目录到临时工作区，再用 EasyM 打开；图片 `assets/em.png` 来自项目已有 v0.2 EM 样例，保持相同字节。样例是后续实现的固定输入，当前并不代表 DOCX、历史或批图已实现。

| 样例 | 用途 | 预期 |
| --- | --- | --- |
| [办公导出](办公导出.md) | 基础结构、中文/emoji、嵌套格式、列表、任务、引用、代码、表格与图片 | 结构可编辑，编号起始值保留，两处图片独立表达，源 Markdown 不改写 |
| [降级与安全](降级与安全.md) | front matter、HTML、危险链接、远程/缺失图片和超宽表格 | 静态保留未知内容，有预检和占位选择，无脚本执行或网络图片读取 |

第 3 步另外生成大表格、长代码、5 MiB 正文、BOM/CRLF 和大小边界样例，生成器与报告注明规模和散列。第 4/5 步以办公导出为基础复制临时文件，制造外部修改、图片缺失、同图多实例、故障与历史恢复；不得修改仓库内样例作为验收操作。

实际 DOCX/PDF、截图、临时历史和损坏样例放入 `test-results/`，不提交二进制输出。正式证据记录输入散列、应用版本/提交、目标办公软件与 OS/WebView 版本。验收标准见 [设计与实施计划](../../Easy-Markdown-v0.3-设计与实施计划.md)。
