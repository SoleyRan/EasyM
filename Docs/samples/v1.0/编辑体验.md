# v1.0 编辑体验

请复制到临时工作区再试用。即时渲染和分屏操作最终修改同一份 Markdown 源码，取消操作保留原文。

## 选区与内容工具

拖选 **已有粗体** 或普通文字，浮动工具可应用或取消加粗、斜体、删除线、行内代码和链接。固定格式栏与选区浮动栏可以在设置中独立显示。使用 Alt+F10 进入选区工具；Esc 返回正文。用 Ctrl/⌘+K 修改 [现有链接](https://github.com/SoleyRan/EasyM)，确认后一次撤销恢复。

用“转换为”在正文、标题、引用和列表之间切换；复杂嵌套结构保持源码编辑。

```javascript
const message = '切换语言只改变围栏标记，内容保持';
console.log(message);
```

## 表格

| 功能 | 入口 | 结果 |
| :--- | :---: | ---: |
| 单元格 | 点击编辑表格 | 确认修改 |
| 行列与对齐 | 表格就地工具 | 一次撤销 |
| 草稿 | 取消 / 放弃 | 保留原文 |

单元格编辑用 Tab/Shift+Tab 导航；新建表格最多 20 列、200 行正文和 2,000 单元格。不支持的嵌套或畸形表格使用源码，不能强行重写。

## 快捷入口

在新的普通空行输入 `/`，用中英文关键词过滤并按 Enter 插入。Esc 关闭保留输入；表格或图片取消后也保留 `/关键词`。代码、URL、普通正文中的斜杠不触发。

按 F1 搜索命令；Ctrl/⌘+Alt+O 查找已打开标签或授权工作区 Markdown 文件名。切换工作区后旧结果失效，触限结果会提示缩小查询。

## 外观

EM → 设置：字号 12–24、行高 1.2–2.2、内容宽度自适应或 720/900/1080、代码字号 10–22。关闭代码换行时仅代码内容横向滚动，普通正文继续换行。源码中的代码按行独立横向滚动，渲染代码按整块滚动。

跟随系统主题可以分别记忆系统浅色、深色对应的配色。恢复默认外观保留正文、草稿、历史和历史保存位置；编辑外观不改变 HTML/PDF 打印或 DOCX 办公样式。
