# v1.0 数据保护样例

先复制整个目录到临时位置，再按 [体验指南](体验指南.md) 操作，避免自动保存修改仓库样例。

- `merge/clean/`：共同祖先 B、本地 L、磁盘 R 和预期结果；修改不同段落，可直接组合。
- `merge/conflict/`：双方修改同一行，需逐块选择或手工编辑；`expected-manual.md` 是一种人工解决结果。
- `备份示例.md` 与 `assets/em.png`：带本地图片的文档，用于创建、恢复和损坏包拒绝检查。

样例不是自动触发冲突的特殊格式。应用的共同祖先来自最后成功打开/保存的文件，不从旁边的 `base.md` 猜测。自动验收使用生产 Worker 检查这些样例，实际交互请按指南操作。

编辑体验.md、持续写作与恢复.md、办公导出.md、脚注与元数据.md、数学公式.md、Mermaid.md、扩展与导出.md 和降级与安全.md 覆盖日常编辑、Markdown 扩展和输出边界。
