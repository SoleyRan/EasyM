# EasyM v0.2 体验指南

这是普通 Markdown 文件，可在 Windows、macOS、Linux 中打开。请复制到临时工作区后进行编辑，不覆盖项目原样例。

## 1. 源码、分屏和即时渲染

切换三种视图，拖选 **粗体文字**、*斜体文字* 和 ~~删除文字~~。选择工具栏格式后再次点击应取消，撤销后恢复原文。

> 在即时渲染模式中，活动块保留 Markdown 源码，其他块显示排版。输入中文时检查候选框与组合文字，不能以粘贴中文代替输入法验收。

## 2. 查找与替换

测试标记：EasyM / easym / EASYM / 中文 / 中文🙂 / $1。

Ctrl/Cmd+F 打开查找；分别测试大小写、整词、下一项和上一项。把“测试标记”替换为“验收标记”，再撤销，正文应完整恢复。整词不是中文分词。
