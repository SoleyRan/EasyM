# v0.5 冻结验收样例

复制整个目录到临时工作区，再用 EasyM 打开；图片 `assets/em.png` 来自项目已有 v0.2 EM 样例，保持相同字节。[体验指南](体验指南.md) 覆盖办公导出、版本历史、批图和键盘路径；下列固定样例的自动化结果及实机缺口见阶段验收记录，样例自身不代表验收通过。

| 样例 | 用途 | 预期 |
| --- | --- | --- |
| [持续写作与恢复](持续写作与恢复.md) | 草稿、最近打开、重启与外部冲突 | 原文件和本地编辑各自保留，明确选择后加载或另存 |
| [编辑体验](编辑体验.md) | 表格、选区/链接/语言/段落工具、快捷入口、外观 | 取消保留原文，确认可撤销，外观不影响导出 |
| [办公导出](办公导出.md) | 基础结构、中文/emoji、嵌套格式、列表、任务、引用、代码、表格与图片 | 结构可编辑，编号起始值保留，两处图片独立表达，源 Markdown 不改写 |
| [降级与安全](降级与安全.md) | front matter、HTML、危险链接、远程/缺失图片和超宽表格 | 静态保留未知内容，有预检和占位选择，无脚本执行或网络图片读取 |

性能验收另外生成大表格、长代码、5 MiB 正文、BOM/CRLF 和大小边界样例，生成器与报告注明规模和散列。历史和批图回归以办公导出为基础复制临时文件，制造外部修改、图片缺失、同图多实例、故障与历史恢复；不得修改仓库内样例作为验收操作。

实际 DOCX/PDF、截图、临时历史和损坏样例放入 `test-results/`，不提交二进制输出。正式证据记录输入散列、应用版本/提交、目标办公软件与 OS/WebView 版本。验收标准见 [设计与实施计划](../../Easy-Markdown-v0.5-设计与实施计划.md)。
