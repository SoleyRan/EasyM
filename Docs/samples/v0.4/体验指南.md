# EasyM v0.4 体验指南

复制整个 samples 目录到临时工作区再编辑。Windows 开发包未签名，需要系统 WebView2；macOS/Linux 原生 GUI 尚待对应设备验收。

## 1. 基础编辑与键盘

先打开 [编辑体验](编辑体验.md)，检查可视化表格、就地工具、`/` 插入、F1 命令面板、Ctrl/⌘+Alt+O 快速打开，以及排版与系统主题设置。四页使用导引会在首次打开或升级到 0.4.0 后显示。

切换源码、分屏、即时渲染，拖选 **粗体**、*斜体*、~~删除线~~ 并应用/取消格式，撤销恢复。输入中文时检查真实候选框和组合输入。打开多个文件，检查标签右键关闭、文件树与大纲、四种配色、查找替换和阅读模式 Esc 退出。

从 EM 菜单使用方向键、Enter、Esc；对话框 Tab/Shift+Tab 焦点保持在窗口内，退出回到触发位置。开启系统“减少动画”检查过渡。键盘自动化通过不代表所有读屏软件均已实机验收。

## 2. DOCX 办公导出

打开 [办公导出](办公导出.md)，编辑但暂不保存，再从 EM 菜单导出 DOCX。分别选择 A4/Letter 和默认/紧凑样式，打开 Word 或自己的办公软件检查标题、列表起始编号、中文/emoji、表格、代码和图片。导出应包含内存修改，不清除未保存标记或撤销栈。字体和分页由目标办公软件决定。

打开 [降级与安全](降级与安全.md)，查看可定位警告。缺图默认阻止生成；明确选择图片占位才继续，原始 HTML、front matter 和未支持内容静态保留。取消预检或另存对话框后返回编辑，原文不变。

## 3. 本地版本历史

将文档保存到临时目录，在 EM 菜单明确启用“版本历史”。历史默认位于文档目录的 `.easym/history/`，含正文和图片；分享整个目录时一并注意这些数据。EM → 设置可更改当前文档目录共用的历史位置，切换会复制并校验已有历史，保留原副本。

创建命名快照，修改文字后查看文字/图片差异，确认恢复。恢复后一次撤销返回恢复前状态；重启应用仍可读取快照。另存快照副本应使用独立文件身份。清理前先审查计划，固定/手动快照不自动淘汰；清理不能删正文或 assets 图片。

## 4. 批量图片

本文件包含两次引用同一 PNG，可检查逐实例选择：

![第一个 EM](assets/em.png)

![第二个 EM](assets/em.png)

先保存并启用历史，再打开“批量处理图片”。只选择一个实例，设定最大长边、PNG/JPEG 和去元数据，查看实际生成的尺寸/体积与前后对照。透明图转 JPEG 要选择背景色。取消不改文档；应用后未选实例不变，整批一次撤销/重做。关闭重开验证保存和恢复。

一次最多 100 个实例，远程/缺失图片不可选择。处理生成不可变副本，原始资源及历史仍保留原字节与元数据；去元数据不表示整份历史匿名。

## 5. HTML 和 PDF

HTML 导出内联授权 PNG/JPEG，离线复制后仍能看到 EM。PDF 在 v0.4 继续通过系统打印，预览返回/Esc 后可继续编辑；专用引擎仅完成评估，尚未接入直接 PDF 导出。检查系统打印的长表格、代码、大图片和取消；实际分页受系统 WebView/字体影响。

## 6. 验收清单

- [ ] 首次启动或更新后的导引可关闭，同版本重启不重复；设置中可重新查看
- [ ] 设置里的主题、字号、格式工具栏显示重启后保持；历史目录切换后旧快照和图片仍可读取
- [ ] 中文输入法、任意拖选、格式切换和撤销正确
- [ ] 原生 DOCX/HTML 另存取消保留正文，目标文件冲突不覆盖新外部版本
- [ ] 历史启用、重启、差异、恢复、另存与清理不丢数据
- [ ] 批图取消、整批撤销/重做、自动保存和重启后图片正确
- [ ] 系统打印/PDF 返回、保存与取消正确，长内容完整
- [ ] 读屏名称、焦点、状态播报与实际键盘操作可用

本清单是实机待验收项，不代表已全部通过。开发与本机自动化结果见仓库 v0.4 验收与交付记录。
