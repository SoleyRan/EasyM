# EasyM v0.6 体验指南

复制整个 samples 目录到临时工作区。Windows 开发包需要 WebView2，当前为未签名开发候选。

## 1. 打开与编辑

EM 菜单可新建、打开、打开工作区或最近文件。标签支持滚轮浏览和右键批量关闭。源码、分屏、即时渲染可切换；F1 搜索命令，Ctrl/⌘+Alt+O 快速打开。选中文字后用工具栏切换格式；表格可编辑单元格、行列与对齐。

## 2. 自动保存与历史

已保存文档停止输入 1.2 秒后自动保存。新文档先保存本机草稿，首次需要另存。重启恢复标签；未完成草稿确认后成为独立副本。有外部冲突时暂停自动保存，比较后再决定。EM → 版本历史显式启用后记录本地正文与图片；历史目录可在设置中修改。草稿和历史不能代替备份。

## 3. v0.6 Markdown 扩展

打开“扩展与导出.md”。脚注用 `[^说明]` 和 `[^说明]: 内容`；文件开头 YAML `---` 或 TOML `+++` 元数据只展示原文，不执行配置。行内公式用 `$…$`，块公式用各占一行的 `$$`。图表使用 mermaid 代码围栏，当前保证 flowchart/graph 和 sequenceDiagram。公式和图表均离线渲染，支持独立设置开关；错误、超限或关闭时保留源码。

## 4. 导出与阅读

EM → 导出右侧选择 HTML、DOCX 或 PDF。HTML 单文件内联授权本地图片、静态 MathML 和清理后的 SVG 图片，可离线查看；PDF 通过系统打印另存，脚注位于文末。DOCX 可继续编辑，脚注输出文末说明，元数据保持原文，公式与 Mermaid 输出完整源码并在预检提示。使用支持 MathML 的现代浏览器打开 HTML；各系统打印分页可能不同。阅读模式只显示预览，Esc 退出。
