# EasyM v0.7 体验指南

复制整个 samples 目录到临时工作区。此版本为未签名开发候选，Windows 需要 WebView2。

## 编辑与原有功能

EM 菜单新建、打开文件/工作区或最近文件。标签可滚轮浏览和右键批量关闭。源码、分屏、即时渲染可切换；F1 搜索命令，Ctrl/⌘+Alt+O 快速打开。已保存文件停止输入 1.2 秒后自动保存；新文档需首次另存。脚注、Front Matter、公式、Mermaid 与 HTML/DOCX/PDF 导出保持原有契约，见仓库 v0.6 样例。

## 体验不同段落合并

1. 在临时目录把 `merge/clean/base.md` 复制为 `working.md`，用 EasyM 打开。
2. 为避免本地编辑先被自动保存，用外部编辑器先把 `working.md` 改为 `disk.md` 内容并保存；暂不切回 EasyM。
3. 切回 EasyM，等待磁盘变化提示。在本地编辑区把“本周：整理需求。”改成 `local.md` 对应句子；本地有差异时自动保存会保持暂停。若没有提示，先确认磁盘版本已变化再编辑。
4. 打开外部版本比较，分析三方合并。审查候选：两处更改都保留，对应 `expected.md`。确认保存格式与应用，磁盘应得到该结果。

若切回时已加载新基线或误先保存本地编辑，请重新复制 base 并打开，保证 B/L/R 对应。不要在唯一原件上练习。

## 体验冲突与恢复记录

按上一节流程使用 `merge/conflict/`。同一行的周六/周日会产生冲突，选择本地、磁盘或手工文本。可参考 `expected-manual.md`；未解决时不能应用。确认后合并作为一次可撤销编辑，撤销恢复本地正文，后续自动保存仍按当前磁盘基线检查。

应用前强制归档基线/本地/磁盘/候选到文档旁 `.easym/merges/`，不依赖普通历史开关。EM → 合并恢复记录中选择版本恢复到新目录。记录存在不表示合并提交成功，归档后再次发生磁盘竞争也会保留记录。原有本地图片没有字节见证时会阻止应用，请另存本地副本；不支持推断图片冲突。磁盘在审查后变化需重新比较。

## 创建与恢复备份

1. 打开复制后的 `备份示例.md`，确认图片显示。EM → 文档备份与恢复 → 创建备份，另选 `.easym-backup.zip` 路径。备份包含打开面板时的正文（含未保存编辑），并保留编码/BOM/换行；取消不会写回原文。
2. 若需要历史，先从 EM → 版本历史显式启用并记录/命名/固定快照，再打开备份面板勾选包含历史。默认不包含；仅收集此文档已登记的历史，支持设置中的自定义历史位置，不复制位置配置或合并恢复记录。
3. 选择并校验备份，查看文件名、时间、大小与历史范围，勾选确认后选择父目录。恢复在新的 `EasyM-restored-UUID` 目录中完成，再通过 EM → 打开文件打开其中的 Markdown，核对文字、图片与可选历史。
4. 原文件、当前编辑和原备份保留。恢复不覆盖已有文档。将备份复制到独立存储；同盘副本不能防止整个磁盘损坏。

只归档支持的本地 PNG/JPEG；远程图片保留链接，不下载。缺图、不安全路径、损坏/新版包、超限或审查后包发生变化都会拒绝；重新选择有效包。混合换行正文编辑后需先另存并确认格式。取消不发布恢复目录。此功能是单文档包，不是完整工作区、定时备份或云同步。
