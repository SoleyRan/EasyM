# 脚注与元数据

Front Matter 作为静态原文展示，不会改变应用设置。

首次引用按出现顺序编号[^说明]，再次引用仍用同一编号[^说明]。
另一条脚注[^导出]说明导出行为，缺失定义保持原文[^缺失]。

## 使用方式

分屏和阅读模式点击上标跳到脚注，点击返回箭头回到对应引用。
键盘 Tab 聚焦引用后按 Enter 同样可以跳转。

[^导出]: HTML 包含静态锚点；系统打印/PDF 使用文末脚注区。

    DOCX 使用可编辑上标与文末脚注，不是 Word 原生逐页脚注。

[^说明]: 脚注里支持 **加粗**、*斜体*、`代码` 和 [安全链接](https://example.com)。

    第二段也保留。

    - 列表项目一
    - 列表项目二

[^说明]: 这是重复定义，会作为静态原文保留。

[^未引用]: 这条未被引用，也不会丢失。
