# v0.3 补充：设置与使用导引

## 用户入口与行为

EM 菜单新增「设置」。外观与编辑设置包含四种配色、格式工具栏显示和编辑字号（12–24 px），即时生效并在本机持久化。配色统一通过设置调整，移除 EM 菜单中的 Style 子菜单；工具栏显示按钮仍与设置保持同步。

EM →「导出」点击后在右侧显示 HTML、DOCX、PDF 三项。HTML 和 DOCX 保持现有导出流程；PDF 打开正文打印预览，再通过系统打印窗口另存为 PDF。子菜单支持上下方向键、Home/End，右方向键展开，左方向键或 Esc 返回父菜单，再按 Esc 关闭 EM 菜单。保存、输入法组合输入或图片编辑等阻塞状态下，导出入口与格式选项均不可用。

首次启动、应用版本与已确认版本不同时显示简要导引，分为四页：开始写作、编辑与自动保存、版本历史、图片/导出/阅读。每次只显示一个部分，通过右箭头翻到下一页，左箭头返回，并显示当前页码；也支持键盘左右方向键。最后一页显示「开始使用」。点击「开始使用」、关闭按钮或 Esc 均确认当前版本；同版本重启不重复显示。设置中可以随时重新查看，每次从第一页开始。应用版本读取 package.json，避免更新版本时遗漏提示判断。无法写入本机存储时保留本次使用，提示下次可能重复显示。

设置和导引使用主题配色，限制 Tab/Shift+Tab 焦点在对话框中，关闭后回到 EM 按钮。打开期间编辑区与标签栏 inert，暂停编辑和自动保存。历史位置切换过程中关闭、Esc 和重复提交均受阻，直至操作完成。原生目录选择取消保持原设置。

## 历史保存位置

此设置以**当前已保存文档所在目录**为单位；同目录文档共用历史库。草稿没有磁盘目录，需要先另存；浏览器版不能修改桌面历史位置。默认仍为文档目录的 `.easym/history/`，启用历史仍需显式操作。

选择自定义位置时，在用户选择的目录内创建 `EasyM-history/<文档目录哈希>/<迁移 UUID>/`，不同文档目录不会混用，重复切换不覆盖已有库。设置显示实际历史位置和作用的文档目录。位置配置写入文档目录的 `.easym/history-location.json`，重启后继续读取；正文、assets 和事务日志仍保存在文档目录。

迁移与保存、快照和批处理共用 Rust 文件操作队列。先复核索引、清单、正文和可用图片哈希，处理待完成历史记录，再复制整个历史库、同步文件并验证复制字节。完成复制后原子提交位置配置。原库保留；目标错误、损坏或不可访问时不会静默建立空历史库。切换不会修改正文或启用历史。

「恢复默认目录」也复制当前有效库。原默认位置已有旧副本时，先保留为 `.easym/history-backup-<UUID>/`，再放入当前库；自定义原副本继续保留。程序不自动删除这些迁移备份。若位置配置提交失败，原生效位置仍是数据来源。

迁移上限为 4 GiB、50,000 个条目；单文件上限 128 MiB。拒绝符号链接、非普通文件、嵌入原库的目标和非法配置。自定义目录需持续可访问；移动文档目录时配置和外置库需一起保留，复制到另一台设备后需保证配置路径有效。它不提供云同步、多人并发写库或设备备份。
