# v0.7 CI 修复：macOS 备份路径

对应运行：[38867406186](https://github.com/SoleyRan/EasyM/actions/runs/38867406186)，提交 `6149fd3`。前端、Windows 与 Ubuntu 作业通过，macOS 的 Rust 测试有 5 项失败，其余 91 项通过。失败集中在备份发布、恢复、包含历史的备份及恢复凭据重读，错误为 `permission_denied`。

macOS 默认临时目录可能经过 `/var` 等系统符号链接。备份内部函数使用 `checked_document` 检查规范化路径，却收到了未规范化的测试临时目录；历史内容验证内部创建的临时目录也存在同样问题，影响实际含历史的备份。

修复包括：在应用自己创建的历史验证临时目录上取得规范化根路径；在原生保存、打开备份、选择恢复目录时固定选择器授权的规范化位置；测试临时目录统一从规范化的系统临时根目录创建。保存目标只解析父目录，保留目标文件的“不覆盖已有文件”检查。

后续重读、发布和恢复继续使用已授权路径逐层检查，不在这些位置重新解析符号链接。新增 Unix 测试覆盖从目录别名取得授权、备份与恢复成功、拒绝未经解析的别名，以及已授权目录被符号链接替换后拒绝重读和写入。

本机验证：`cargo test --manifest-path src-tauri/Cargo.toml --locked --offline`，Windows 91 项通过；`git diff --check` 通过。新增 Unix 测试尚未在本机执行，macOS 和 Linux 结果需由修复提交后的 CI 确认。本记录不修改第四步归档的历史验收证据，也不代表安装包已重新构建。
