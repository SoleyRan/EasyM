# EasyM v0.4 第二步：可视化表格编辑

日期：2026-10-13。分支：`feature/v0.4`。上一阶段提交：`ae3e216`。本步遵循冻结设计第 5 节，产品版本仍为 `0.3.0`，不生成安装包。

## 功能与使用

格式工具栏和编辑区右键提供“插入表格”及“编辑表格”，统一走命令注册表。插入面板提供正文行数、列数和 6×5 网格选择器，默认 3 列、2 行正文，另外保留一行表头。创建空表后进入首个表头单元格；取消创建不改变正文。

源码位置可定位当前表格。分屏预览提供编辑和源码按钮，点击具体单元格定位到该单元格；即时渲染提供相同的编辑/源码入口。阅读模式没有编辑入口。预览结果与当前正文不一致时拒绝使用旧范围，重新解析后再操作。

表格编辑面板显示当前行列、单元格 Markdown 输入、延迟 120 ms 的草稿渲染预览、单元格导航和结构操作。不把预览 DOM 设为 contenteditable，也不从 HTML 生成正文。

- Enter 或“确认”：应用当前单元格并返回源码。
- Esc 或“取消输入”：放弃本次单元格草稿，保留之前已应用的修改。
- Tab / Shift+Tab：应用当前输入并移动到下一/上一格；末格 Tab 新增一行并进入首格；首格 Shift+Tab 返回表格前可用源码位置。
- 点击导航中的其他格：先提交当前输入，成功后切换；失败保留草稿。
- 上方/下方插入正文行、左侧/右侧插列、删除当前行列，以及左/中/右/默认列对齐。表头和最后一行正文、最后一列受到保护。删除含内容的行列先确认。

单元格输入展示 Markdown 原文，支持强调、链接、代码和已有转义。未转义的竖线提交时变为 `\|`，包括行内代码中的竖线。非法换行拒绝提交，不压平内容；失败保留输入并显示原因，可重试、复制或取消。

## 正文与源码映射

`src/core/tables.ts` 先通过共享 Markdown AST 确认顶层 GFM 表格，再扫描实际源码行。扫描依据竖线前反斜杠数量的奇偶判断分隔符，处理可选的首尾竖线、空格、空格内容单元格、空单元格、中文和 emoji。范围使用 UTF-16 offset，与 CodeMirror 一致；单元格另记录含边界空白的范围，供预览 AST 位置定位。

扫描结果与共享解析器确认列数、行数和分隔行，并在原文前后上下文中重新解析规范化表格，比较剔除位置信息后的 AST 语义。保留引用链接定义等上下文；无法确认一致性时提供源码编辑提示，拒绝猜测或丢弃单元格。

普通单元格编辑只替换该格的内容范围。插删行列和对齐允许重建目标表格，保留其余单元格 Markdown 原文、转义、对齐与表格换行约定；表格外的正文不变。仅打开、显示、取消工具不美化文件。BOM、编码和文件换行继续由既有文件契约保存，单元格补丁使用实际源码 offset，支持 CRLF/LF 和混合换行定位。

本轮只编辑顶层、完整、矩形且可可靠映射的 GFM 表格。嵌套在引用/列表中的表格、缺省或多余单元格、仅有表头等结构仍可渲染及源码编辑，不自动正规化。上限为 20 列、200 行正文、2,000 单元格（包含表头）、100,000 源码字符；单元格输入上限 10,000 字符。创建和增大表格时检查相同上限。

## 草稿、锁与撤销

`TableSession` 保存表格映射、当前格、草稿和捕获的命令上下文。源码编辑器在工具打开期间暂停输入，保持同一 CodeMirror 实例与撤销栈。提交重新检查目标标签、文件身份、revision、选区及输入法/任务锁；过期目标不改写正文，草稿保留。

切换标签、模式、新建、关闭、导出、打开历史/设置等操作先处理表格草稿：应用成功后继续，放弃后继续且不改正文，取消则留在工具。应用失败不执行后续操作。确认弹窗阻止底层工具及顶栏交互，关闭后恢复输入焦点。

表格工具打开期间暂停该文档自动写回，避免把尚未应用输入误称为已保存；退出后按原有自动保存规则继续。正文草稿恢复仍保留已应用的 Markdown；未提交的单元格输入仅保存在当前会话内存，不新增持久草稿格式。浏览器离开页面触发未保存保护，不能据此声称能恢复进程崩溃时的未提交单元格。

修改通过 `EditCommandResult` 一次应用局部 `TextPatch`。单元格修改、结构操作各为一个撤销步骤，末格输入加新增行合为一步；无变化确认不添加撤销记录。Tab 即使没有正文变化也单独移动光标，工具关闭返回相应源码位置。组合输入期间 Enter、Tab、Esc、鼠标确认、结构操作和离开均受保护。

## 验证与交付边界

新增 `pnpm verify:tables`，纳入 `pnpm verify:regression`；CI 上传表格报告及主题/紧凑窗口截图。证据归档在 `Docs/verification/v0.4/step-2/`，临时日志位于忽略目录 `test-results/`。

单元测试覆盖源码映射、转义、引用、中文/emoji、CRLF/BOM、矩形和上限拒绝、局部补丁、结构修改、删除确认、输入法组合保护，以及过期表格目标和导出前应用失败保留草稿。生产 Chromium 验证覆盖创建/撤销/重做、单元格输入、Tab 新增行、增删行列/对齐、非法换行、切换/关闭保护、四主题、紧凑窗口、即时渲染和阅读模式；模拟桌面 IPC 验证未提交草稿期间暂停自动保存，应用后保存包含新正文。

完整回归保留旧表格源码入口检查，同时更新即时渲染点击单元格的预期：先进入编辑工具，取消后检查源码，再显式验证“显示表格源码”。不取消原有文字拖选、查找、文件、图片、历史和导出断言。最终命令与结果见同目录 `acceptance.json` 和原始报告。

模拟 IPC 不是真实原生文件写入；合成 composition 事件不是真实输入法候选验收。真实 IME、原生确认/文件/打印对话框、读屏、macOS/Linux GUI 及远端 CI 仍需后续验证。Rust 代码和依赖未修改；本步不重复 Rust 全量测试或发布 Windows 包。既有大包体构建提示保留，性能与交付按第 5 步处理。

实现独立编写，没有导入 MarkText 代码、资源或许可文本。第三步将实现选区浮动格式工具、链接就地工具、代码语言及段落转换。
