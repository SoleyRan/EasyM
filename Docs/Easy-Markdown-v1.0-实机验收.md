## 发布判定

保存/恢复丢失、静默覆盖外部文件、损坏资源/历史、路径逃逸或必需 CI 失败均阻断发布。任何失败先附复现、日志和候选哈希，再修复或明确调整支持范围；不能把未验直接标成通过。

正式发布还需确定签名/公证及人工下载安装策略、完成 macOS 上游 SDK 分发复核。当前无自动更新；不要承诺更新签名。三平台全部通过后，使用同一成功 CI 的候选生成 Release 草稿，核对完整资产和 `SHA256SUMS.txt` 后再公开。
