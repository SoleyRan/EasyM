# EasyM v0.4 设计与实施计划

冻结日期：2026-10-13。开发分支：`feature/v0.4`。代码基线：`2c73d57`（v0.3 合并提交），产品版本仍为 `0.3.0`。本文冻结下一阶段范围、交互与数据契约、实现顺序和验收门槛；设计冻结不表示功能已经实现。

## 1. 阶段目标

v0.4 聚焦写作与编辑体验：让用户直接操作表格，在选区或内容附近调整格式，并通过快捷插入、命令搜索和文件搜索减少寻找工具的操作。

沿用 Tauri、React、CodeMirror 6、共享 Markdown AST 与 Worker。Markdown 原文仍是唯一正文；源码、分屏和即时渲染共用同一个文档状态及撤销栈，阅读模式保持只读。既有自动保存、草稿、历史、图片处理、HTML/DOCX 导出和系统打印继续受原数据契约约束。

MarkText 仅作为交互设计研究参考：表格就地操作、选区工具、快捷插入、段落转换和命令搜索。EasyM 独立设计和编写实现，不复制其代码、测试文件、图标、图片、CSS 或文案，不引入 Muya，也不因这一设计参考新增 MarkText 的 MIT 许可声明。现有依赖许可记录继续保留；若后续实际新增依赖，仍按项目既有流程记录该依赖的许可。

本轮不重新加入此前已替换为阅读模式的“专注模式”，不新增打字机模式。

## 3. 基线与通用约束

基线功能与限制见 [v0.3 设计计划](Easy-Markdown-v0.3-设计与实施计划.md)、[v0.3 设置与导引](Easy-Markdown-v0.3-设置与使用导引.md)、[v0.3 验收与交付](Easy-Markdown-v0.3-验收与交付.md)。提交 `efcfe0b` 的 [CI 第 2 次运行](https://github.com/SoleyRan/EasyM/actions/runs/38367149201/attempts/2) 前端、Windows、macOS、Linux 均通过，包括 Windows 原生启动、安装/卸载和便携包校验。首次 Windows 运行因 hosted runner 失联失败，同一提交重跑通过。

远程编译与自动化通过不表示真实 IME、系统文件/打印对话框、读屏、跨平台 GUI 和办公软件全部通过；既有实机缺口继续单独记录。当前本地 main 合并另行处理，本阶段不修改 main。

- 显示、选中、打开工具或取消操作不改变正文、脏状态、文档身份及撤销栈。编辑只提交局部 `TextPatch`；不把预览 DOM 或富文本 HTML 序列化回全文。
- 保留 UTF-8/BOM、CRLF/LF 与未修改文件原始字节；继续使用现有混合换行确认规则。不在显示表格时自动格式化文件。
- 每次结构操作作为一个独立撤销步骤；普通连续输入保持原有分组。撤销/重做恢复正文、合理选区和当前编辑位置，不创建第二个正文历史。
- 所有修改命令重新检查目标标签、文件身份、正文 revision、输入法状态、阅读/模态/保存/图片/导出等锁。执行入口统一检查，不能仅依靠按钮 disabled。
- 异步结果与源范围绑定文档身份和 revision。切换文档、修改正文、重载、恢复历史后，过期结果不能应用。必要时重新读取当前语法结构；无法确认时说明原因并提供源码入口。
- 输入法组合期间不转换结构、提交单元格、接受快捷插入或执行编辑快捷键；Enter/Tab/Esc 和候选选择优先交给 IME。组合结束后重新判断，不用合成 composition 事件宣称真实输入法通过。
- 任意文字拖选继续保持实际起止位置；不能自动扩大成整段、整表或代码块。普通文字选区与工具操作选区明确区分。
- 本地路径、图片和链接继续通过现有授权及安全接口处理。工具不执行原始 HTML、代码或文档指令，不主动抓取远程图片，不上传正文。
- 新组件须支持四种现有主题、紧凑窗口、键盘路径及减少动画偏好。派生界面不导致主编辑器重复挂载或重置撤销栈。

## 4. 第一步：统一命令与浮层

### 4.1 命令契约

建立内部命令注册表。一个命令包含稳定 ID、中文名称、英文搜索别名、分组、可选快捷键、上下文可用状态和执行函数。可用状态返回允许/禁止及原因；格式类额外返回未选中、选中或混合状态。

上下文至少包含目标文档/标签身份、正文 revision、主选区、编辑模式、composition 状态及任务锁。不同入口共享同一命令：EM 菜单、固定工具栏、右键、浮动工具、快捷键、`/` 和命令面板不得各自实现正文改写。

优先迁移本轮涉及的格式、表格、链接、代码语言、插入、切换视图、导出、历史和文件打开命令。原生 IO 继续由现有平台接口承担；注册表不授予额外文件访问能力。

编辑结果沿用 `EditCommandResult`（`baseTextRevision`、`patches`、可选 `selection`）。分发前检查 revision、整数边界、范围重叠和目标身份，过期结果拒绝应用。无改动命令不进入撤销栈、不触发自动保存。

本轮保持既有快捷键含义，包括 `Ctrl/Cmd+P` 打印与 `Ctrl/Cmd+Shift+P` 插入图片。命令面板默认使用 `F1`，快速打开默认使用 `Ctrl/Cmd+Alt+O`，并提供菜单入口。快捷键须在三个平台验证，不拦截 IME 候选键和原生输入框的常规编辑。

### 4.2 浮层契约

建立应用级浮层宿主与生命周期管理，管理位置、目标上下文、可见状态、Esc 和焦点恢复。优先级从低到高：被动选区工具、内容工具/快捷插入、应用菜单/右键、模态对话框。系统原生对话框仍由平台接口管理。

- 同一时刻仅有一个主要可交互的非模态浮层；打开 EM、右键或模态窗口时关闭较低层。选区工具不遮挡当前操作入口。
- 浮层通过 Portal 脱离编辑区裁剪和滚动容器；位置根据锚点与可用窗口空间翻转/限位，避免固定增加 z-index 仍被父层遮挡。
- 主动菜单接管自身的方向键/Enter；被动选区工具不吞掉正文输入、删除、Enter 或方向键。关闭最上层后停止传播 Esc，避免同时退出阅读模式或关闭查找。
- 鼠标从选区移向工具时保持选区；工具内部输入框允许正常选择和剪贴板操作。正文重新输入、开始拖选、锚点离开视口、目标失效或开始 composition 时隐藏被动工具。
- 异步定位带代次校验，关闭后过期定位结果不能再次显示浮层。滚动/缩放/侧栏拖拽后更新位置；销毁时清理监听器和任务。
- 非模态工具关闭后回到有效正文选区；模态对话框管理焦点循环并恢复到发起入口。无法恢复到已关闭标签时回到当前标签的可操作入口。

第一步验收：既有菜单、右键、查找、格式、模态和阅读模式行为不回退；真实鼠标拖选、工具点击后保留选区、IME 防护、过期命令拒绝和浮层竞态有验证。

## 5. 第二步：可视化表格编辑

### 5.1 用户流程

新增“插入表格”命令，提供行列数输入和简洁网格选择。默认 3 列、2 行正文，另有 1 行表头；行数标签明确为“正文行数”。插入后定位到首个表头单元格。单元格初始为空，插入本身作为一次修改和一个撤销步骤。

源码、分屏均可通过当前源码位置定位表格并打开就地编辑；即时渲染中的表格提供明确“编辑表格”和“源码”入口，点击具体单元格可进入对应位置。分屏预览上的编辑入口仍将修改提交到当前源码文档。阅读模式不显示编辑工具。

编辑工具包含当前行列提示、单元格 Markdown 输入、渲染结果和行列操作。先提供稳定的单元格输入区域/覆盖层，不将整张预览表设为任意 contenteditable。保留单元格中的强调、链接、代码等 Markdown 原文。

- 单元格输入实时反馈当前草稿渲染；点击确认或非 composition 状态下 Enter 提交并结束该次编辑。Esc 取消该次尚未提交的输入。
- Tab/Shift+Tab 提交当前单元格并移动到下一/上一单元格，跨行继续；末尾 Tab 新建一行并进入其首格，表格起点 Shift+Tab 返回源码表格前的可用位置。
- 其他鼠标/键盘导航只有在当前输入成功提交或明确取消后执行。无改动确认不产生 undo；单元格修改与末尾新增行在同次 Tab 中作为一个撤销步骤。
- 行菜单：上方/下方插入正文行、删除当前正文行。列菜单：左侧/右侧插入、删除、左/中/右/默认对齐。
- 表头保留为一行，不提供删除表头；删除最后一列或最后一行正文时禁用该操作并提示。删除含内容的行列需要确认，允许一次撤销恢复。
- 提交错误保留输入草稿与原文，提供重试/复制草稿/取消；目标失效不能将草稿写入其他位置。

存在未提交单元格草稿时暂停该文档自动保存；切换标签、模式、关闭、导出、历史恢复等操作须先提示“应用 / 放弃 / 取消”。应用成功后按现有流程继续；放弃不改变正文；取消保留工具。不能把尚未应用的输入当成已保存正文。

### 5.2 源码映射与支持边界

以共享解析器确认 GFM 表格类型，再由独立表格模块解析原文范围、行、分隔行、列对齐、单元格范围和内容。映射使用源码 UTF-16 offset，与 CodeMirror 和现有命令一致；不能通过 HTML `textContent` 推断源文。

扫描需要正确处理转义竖线、反斜杠、行内代码、空单元格、行首尾可选竖线和中文/emoji。若源码拆分与共享 AST 的列/内容语义无法对应，禁用可视化修改并解释原因；不能用简单 `split('|')` 或静默丢弃多余内容。

- 已有单元格内容只改写该单元格范围；未编辑的内容、引用、转义和前后正文保持原样。输入区域展示 Markdown 源内容；输入未转义的竖线需提示并在提交时转为 `\|`，非法换行拒绝提交而不静默压平。
- 插删行列可以重建必要的表格行或整个目标表格，保持未修改单元格语义和转义、现有对齐与换行约定；不重写全文，不自动对所有表格做美化。
- 新表格使用标准 GFM 写法：首尾竖线、单元格外侧各一个空格、分隔行至少三个短横线。对齐用冒号表达，不通过 HTML/CSS 写入额外 Markdown 方言。
- 本轮支持顶层、完整且列数一致的 GFM 表格。引用/列表内部表格、缺省/多余单元格的非矩形表格或解析不明确的结构继续显示和源码编辑，但不自动正规化为可视化表格。
- 一张表可视化上限：20 列、含表头最多 201 行、最多 2,000 单元格、目标源范围最多 100,000 UTF-16 单位，任一超限回退源码并提示。单元格输入不超过 10,000 UTF-16 单位。
- 超过既有即时渲染文档/长行阈值时沿用降级，不强行加载大量表格 DOM。插入/新增前预判上限，禁止超限操作，原文保留。

第二步验收：创建、确认/取消、Tab、行列操作、对齐、删除确认、Undo/Redo、切换/导出时草稿保护、四主题与紧凑窗口通过。单元格映射及转义使用语义和字节/源码范围检查，覆盖 BOM/CRLF、中文/emoji、代码竖线、转义符和畸形表格。

## 6. 第三步：选区与内容就地工具

### 6.1 选区浮动格式工具

默认开启，可在设置中关闭；固定格式工具栏的显示开关独立保留。仅非空且可格式化的文字选区显示。拖选期间不抢焦点，鼠标释放或键盘选区稳定后出现；跨段选区只显示可安全执行的项，代码/不支持混合结构不提供会破坏结构的操作。

提供加粗、斜体、删除线、行内代码和链接；不把已有“围栏代码块”按钮改成行内代码。删除线、行内代码加入统一格式契约，固定工具栏与快捷入口按需同步。

格式状态统一为 false/true/mixed：全覆盖点击取消，未覆盖或混合点击统一应用，不能叠加重复标记。快捷键、右键、固定工具栏或源码修改后，浮动工具状态同步。多段选区不能把换行简单包进不合法的行内标记；使用语法范围逐段处理或明确禁用。

### 6.2 链接工具

统一“插入/编辑链接”入口：无选区时输入显示文字和地址；有文字选区时预填文字；位于现有链接时预填当前目标并编辑该链接，不再生成 `https://example.com` 占位地址。

确认修改、Esc/取消保留原文；解除链接保留显示文字及可保留的行内格式。引用式链接允许转换当前使用处为行内链接，但不修改/删除可能被其他位置使用的定义；UI 明示转换，不隐式改动所有引用。

地址允许现有安全策略支持的 http/https/mailto、页内锚点和相对文档目标；拒绝 javascript/data 等危险 scheme。编辑地址与打开地址分开，普通点击优先编辑，明确“打开”动作复用平台安全策略。相对文档打开需要现有授权，越界目标不新增访问权。

### 6.3 代码语言与段落转换

代码块旁显示当前语言入口，提供中文名称/英文标记搜索、无语言和常见语言选择；保留未知语言标记，不误判为最接近语言。修改只针对当前围栏的 info string，保留代码内容、围栏字符和长度；高亮随实际语言更新，未知语言按纯文本显示。

源码模式仍有现有语言入口；即时渲染/分屏的就地工具提交到同一正文。输入法组合、代码块身份过期、阅读或任务锁期间禁止修改。无语言行为继续遵循现有围栏命令约定。

段落操作提供“转换为”：正文、H1–H6、无序/有序/任务列表、引用；入口使用内容工具和命令面板，源码位置也能调用。默认作用于当前完整段落/所选完整逻辑行，执行前给出明确目标提示。代码、表格、Front matter 和复杂嵌套结构只提供适用操作，不能把代码文本逐行误转换。

本轮转换不新增任意块拖拽、跨层级批量重排。转换保持文本和现有行内格式；移除/替换结构标记局限在目标块，不整体再序列化 Markdown。

第三步验收：格式开关/混合状态/嵌套标记、反向选区、工具不抢选区、跨段/代码禁用、链接取消/引用与安全目标、语言高亮和未知标记、段落转换及撤销均通过。

## 7. 第四步：快捷插入、命令面板与快速打开

### 7.1 `/` 快捷插入

仅普通空段落/行的起始处（可有前导空格）输入 `/` 后触发，继续输入中文或英文关键词过滤。已有正文中的 `/`、URL、文件路径、代码、表格和 Front matter 不触发。composition 期间不显示/接受结果，结束后再判断。

项目包含 H1–H6、无序/有序/任务列表、引用、围栏代码、表格、图片和分隔线，复用已有或本轮统一命令。表格进入行列选择、图片进入现有本地导入流程，不新增网络图片抓取。

方向键/Home/End 选择，Enter 确认，Esc 关闭并保留已输入文字；无匹配时显示空结果。执行前验证原触发范围与 revision；成功时替换本次 `/关键词`，操作可一次撤销恢复它。需要后续对话框的项只在确认成功时替换，取消仍保留原输入，不留下空白结构或半导入资源。

### 7.2 命令面板

EM 菜单提供“命令面板”，快捷键 F1。显示搜索输入、分类、命令名、可用原因和快捷键，支持中文/英文关键词；空查询按固定分组展示，不引入使用统计或遥测。

覆盖编辑格式/插入/表格、查找、视图/阅读、文件打开、导出、历史、批图和设置。不可用命令可见但禁用并说明原因，回车不能绕过任务锁。方向键选择、Enter 执行、Esc 关闭，执行后恢复相应编辑/任务入口。

设置/模态内部不能叠开命令面板；原生输入框仍保留正常快捷键。命令面板不接受或执行任意 JS、shell、路径命令。

### 7.3 快速打开

EM 菜单提供“快速打开”，快捷键 Ctrl/Cmd+Alt+O。默认显示已打开标签（含有名称的草稿），可搜索并切换；有工作区时同时按文件名/相对路径查询授权目录内 `.md`/`.markdown`。同名项显示相对路径与来源，已打开文件复用标签，保留未保存正文。

工作区文件名搜索使用受限后台扫描，不读取正文、不建立全盘索引。沿用隐藏/依赖/构建目录忽略和符号链接拒绝规则；不能递归请求无上限的前端文件树。查询去抖 200 ms，独立请求身份，支持取消与过期结果丢弃。

单次扫描最多 10,000 文件系统条目、深度 32、结果最多 100 条；触限明确显示“结果受限，请缩小查询”，不声明结果完整。仅查当前工作区，切换工作区时取消旧搜索。打开前重新校验授权和文件存在，文件删除/权限错误时保留当前正文并提示。

浏览器演示模式仅支持已打开标签和现有浏览器能力，不模拟成真实磁盘搜索。工作区搜索正文与快速打开文件名入口区分。

第四步验收：触发/不触发、IME、过滤/空结果、键盘、取消后原文、一次撤销、命令忙状态、文件名搜索上限与取消、同名/中文/空格路径、标签复用和工作区变化通过。

## 8. 第五步：排版设置、回归与开发包

### 8.1 设置

| 设置 | 冻结行为 |
| --- | --- |
| 正文字号 | 沿用 12–24 px，与现有设置/持久化兼容 |
| 正文行高 | 默认 1.6，范围 1.2–2.2，步长 0.1；源码/即时渲染/预览/阅读统一应用 |
| 正文宽度 | 默认自适应，另选 720/900/1080 px 最大内容宽度；各面板内居中，不固定窗口或减少侧栏可用性 |
| 代码字号 | 默认 14 px，范围 10–22 px；源码内代码、渲染代码及阅读代码一致 |
| 代码换行 | 默认开启；关闭时仅代码块横向滚动，普通段落继续换行 |
| 跟随系统主题 | 默认关闭以兼容当前设置；开启后分别记忆浅色/深色时所用四主题之一，系统变化实时应用 |
| 选区浮动工具 | 默认开启；不联动固定格式工具栏的显示状态 |

这些是编辑/阅读外观设置，不改变 Markdown 文件、不写入历史快照、不修改 DOCX 办公样式或 HTML/PDF 打印样式。恢复默认只处理这组外观/编辑偏好，不清除草稿、文档历史或历史保存目录。

偏好使用受约束的持久化结构，兼容已有 theme/toolbar/font-size/guide 记录。损坏值或未知字段回退有效默认，不阻塞启动。存储失败保留当前会话设置并提示；不得静默清空已有记录。

### 8.2 性能和资源

保持既有 5 MiB 文档、100 KiB 单行和 100 图片基线及降级策略。正常输入事件到下一帧 p95 目标仍为 50 ms，测试记录设备/浏览器/源规模；无法达标时说明结果和降级，不能删减测试掩盖问题。

表格上限样例和滚动、选区浮层定位加入生产浏览器测量；不在每次 selection-change 序列化全文或遍历全部 DOM。命令注册表不引入大型搜索框架；候选项规模有上限，优先用已有工具与小型独立模块。
