## 尚未完成的实机项目

- 真实中文输入法组合、候选选择、回车和组合期间的工具栏交互仍需要用户使用系统输入法确认。自动化 `type_text` 只能验证 Unicode 文本输入，不能证明 IME composition。
- Windows 原生打印的 PDF 保存、取消和返回编辑后的状态恢复仍需人工完成一次。
- 图片双击编辑副本、剪贴板图片和外部冲突副本需要继续使用用户实际文件/剪贴板验证。
- macOS 和 Linux 的原生文件、输入法、图片、打印和取消路径需要对应设备验证。
