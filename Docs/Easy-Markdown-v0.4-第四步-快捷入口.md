# v0.4 第四步：快捷插入、命令面板与快速打开

本步按冻结范围独立实现三种快捷入口，继续使用 CodeMirror 源码正文、统一命令上下文和应用浮层宿主。产品版本保持 0.3.0，仅参考 MarkText 的交互设计，没有复制其代码、资源或许可文本。

## `/` 快捷插入

普通行开头输入 `/` 可搜索中文或英文关键词，提供 H1–H6、无序/有序/任务列表、引用、围栏代码、表格、图片和分隔线。方向键、Home/End 选择，Enter 执行；Esc 关闭并保留 `/关键词`，无匹配时不修改正文。菜单保持正文焦点，鼠标点击不会丢失插入位置；带修饰键的选区/导航快捷键仍交给编辑器。

触发只接受无选区、行末光标和最多三个前导空格的普通行。正文中的斜杠、URL、多段文件路径、代码、表格、Front matter 和嵌套结构不触发。复用共享 AST 确认段落身份，沿用就地工具 1 Mi 字符上限；普通输入/光标移动先检查当前逻辑行，不为无关位置序列化或解析全文。查询最多 64 字符，composition 期间隐藏且不接受结果，结束后重新判断。

执行重新核对文档身份、revision、选区及触发原文。结构插入只补丁替换当前 `/关键词`，保留目标外正文和换行约定，作为一个撤销步骤。表格先进入已有行列数选择，确认后替换触发范围并打开单元格工具；图片先选择本地 PNG/JPEG，再进入已有图片处理工具。取消选择/后续工具仍保留原文；图片确认沿用原有资源事务，不新增网络图片抓取。

## 命令面板

EM 菜单增加“命令面板”，快捷键 F1。搜索统一命令的中文名称、英文关键词、分类和命令身份，显示分类、当前可用状态/原因、格式状态和平台快捷键。空查询保留固定注册顺序，涵盖格式、插入、表格编辑、查找、视图、文件、导出、历史、批图、模板和设置，不引入遥测或使用排序。

面板接管方向键、Home/End、Enter 和 Esc，正文暂时不可输入，原选区保持用于执行。禁用项可见，Enter 和鼠标均不能绕过命令状态。执行前和实际命令提交时再次校验上下文；面板关闭或交接其他工具后恢复有效入口。模态对话框内不能再打开快捷入口，composition 期间不执行、关闭或启动搜索。快捷入口开启时暂停当前本地文件自动保存，避免保存改变文件身份而让捕获的命令上下文失效。

## 快速打开

EM 菜单增加“快速打开”，快捷键 Ctrl/Cmd+Alt+O。已打开标签可按名称/相对路径筛选，切换保留未保存正文和标签身份；授权工作区同时显示 `.md` / `.markdown` 文件名搜索结果。同名文件显示相对路径和“已打开 / 工作区”来源。浏览器演示明确仅搜索已打开标签。

新增 Rust `search_workspace_filenames` 命令，只枚举授权工作区内的文件系统条目，不读取正文或建立全盘索引。跳过隐藏目录和 `node_modules`、`target`、`dist`、`build`、`coverage`、`test-results`，拒绝符号链接/越界路径。单次扫描上限 10,000 条目、深度 32、100 个结果；触限明确显示“结果受限，请缩小查询”。不可访问条目计入跳过数量，不能把部分结果声明为完整结果。

前端去抖 200 ms，每次搜索有独立 requestId；查询变化、composition、关闭或工作区切换取消旧请求，过期响应不能覆盖新结果。打开文件时再次使用授权工作区命令校验目标并验证编码。相同原生文件身份复用标签，保留当前内存编辑；删除/权限/编码错误显示在面板中，当前正文保持不变。关闭面板取消异步切换，晚到文件句柄只在没有被其他标签持有时回收。

## 验证与边界

新增 `pnpm verify:quick-entry`，纳入完整 `verify:regression` 和 CI 报告上传。专项生产 Chromium 验收覆盖被动焦点、触发/不触发、中文/英文过滤、空结果、键盘/鼠标、Esc、一次 Undo/Redo、表格取消/确认、图片选择取消、命令选区保留/禁用原因/模态交接、标签复用、合成 composition、四主题与紧凑窗口。

桌面 IPC fixture 验证搜索限制提示、同名/中文/空格路径、取消/过期搜索、已有标签未保存编辑保留、过期打开回收新句柄和缺失目标错误。组件测试补充工作区切换取消、晚到旧结果丢弃，以及任务锁/输入法组合期间键盘和鼠标确认禁用。Rust 临时目录测试验证忽略规则、只查询文件名而不解码正文、结果/条目/深度上限及取消；Unix 的链接测试由对应平台 CI 执行。

本机验收通过：前端 41 文件 / 225 项单测、Windows Rust 57 项、类型检查/生产构建、版本一致性、完整生产回归 19/19 组及快捷入口专项 6 组。图片成功路径验证取消后保留触发、确认后替换及一次撤销恢复；验收 fixture 等待编辑器真正解除只读后再写入，避免对话框交接后的状态竞争。结果、源码哈希和四主题/紧凑窗口截图归档于 `Docs/verification/v0.4/step-4/`。

合成 composition 不代替真实中文 IME 候选验证，IPC fixture 不代替原生文件对话框。macOS/Linux GUI、当前源码的远端 CI 和实机项目仍待相应环境执行；本步不生成安装包、不 push，亦不更新产品版本。

下一步为第五步整体：排版偏好、跟随系统主题、性能/完整回归、0.4.0 元数据与导引/样例及 Windows 开发包。
